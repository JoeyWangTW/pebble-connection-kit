# Pebble — connection kit (prototype)

A static, mobile-first prototype that helps people **start, sustain and scale** friendships, built on public social-psychology research. No backend, no login: all state lives in `localStorage`. Messaging and "AI" are clearly labeled templated mocks.

Live: https://joeywangtw.github.io/pebble-connection-kit/

Run locally: `python3 -m http.server` and open http://localhost:8000.
